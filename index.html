How to set up the Worker (one-time, 10–15 min)
  1. Sign in at dash.cloudflare.com (free).
  2. If your marketplace worker is already deployed (pokemon-marketplace.<you>.workers.dev), reuse it — just bind a KV namespace. Otherwise create a new Worker named pokemon-marketplace and paste the bundled code.
  3. In Workers & Pages › KV create a namespace called pokemon-sync.
  4. Open your Worker → Settings › Variables › KV Namespace Bindings, add: variable name SYNC_KV, bind to namespace pokemon-sync.
  5. Re-deploy (paste the latest worker-paste-this.js below), then copy the workers.dev URL into the field above.
  6. On each device: enter the same Worker URL + Pair code. Tap Connect & sync. Done.

How the Model Works
Price = 12.50 × 1.19PullCost × 1.41Desirability
Pull Cost (Supply)

Packs-per-hit × cards-in-tier ÷ 100. Each +1 → +19% price.

Desirability (Demand)

Character (45%) + Artwork (45%) + Appeal (10%). Each +1 → +41% price. Auto-calibrated from market data.

R² = 0.88

Explains 88% of price variation in modern chase cards.
