Save your data to a file you can drop in iCloud Drive (Files app). On your iPhone or iPad, open the same file and tap Import. Works today, no account needed.

Tip for iPhone/iPad: After tapping Export, choose Save to Files and pick iCloud Drive › Pokemon Predictor. iCloud syncs it automatically. On another device, tap Import from file and pick the same backup. Or use AirDrop for one-shot transfers.

Full auto-sync via a tiny Cloudflare Worker (free tier, ~15 min setup). Every change is pushed to your private cloud sync store and pulled by your other devices in the background.

Not connected
How to set up the Worker (one-time, 10–15 min)
  1. Sign in at dash.cloudflare.com (free).
  2. Go to Workers & Pages › Create application › Create Worker. Name it pokemon-sync.
  3. In Settings › Variables › KV Namespace Bindings, add a binding: variable name SYNC, namespace pokemon-sync-store (create it).
  4. Paste the Worker code (download below), deploy, copy the workers.dev URL into the field above.
  5. On each device: enter the same Worker URL + Pair code. Tap Connect & sync. Done.

How the Model Works
Price = 12.50 × 1.19PullCost × 1.41Desirability
Pull Cost (Supply)

Packs-per-hit × cards-in-tier ÷ 100. Each +1 → +19% price.

Desirability (Demand)

Character (45%) + Artwork (45%) + Appeal (10%). Each +1 → +41% price. Auto-calibrated from market data.

R² = 0.88

Explains 88% of price variation in modern chase cards.
